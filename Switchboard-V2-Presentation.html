02Problem
Fig. 02 The problem · section 1 of 3

Business logic moved into no-code automations. The repair workflow didn't move with it.

Condition A

An invisible estate

Zaps, scenarios, and flows built by non-engineers, spread across platforms — no repository, no review, no on-call. They outlive their owners.

Condition B

Failures nobody sees

A renamed column or expired credential kills a flow silently. Two flows fight over the same CRM field across platform boundaries no single vendor can see.

Condition C

Every fix is manual

Find the platform, find the flow, reverse-engineer a stranger's logic, edit it live in production — no diff, no test, no undo.

Diagnosis

Nobody wants a map of their broken automations — they want the automations not broken. The real gap is the repair workflow, not the missing dashboard.

03Solution
Fig. 03 The solution · section 1 of 3

A continuous loop that closes every finding with a verified, reversible fix

Detect

Cross-platform estate graph, run-telemetry baselines, conflict analysis — the sensing layer.

Diagnose

Root cause: which step, which resource, which change broke it.

Fix

Synthesize a definition diff, preview it like a pull request, apply via the platform API on approval.

Verify

Watch telemetry against baseline; confirm recovery; auto-undo if the fix made things worse.

06Features · Core
Fig. 06 Slide A — core features · section 3 of 3

The contribution: detection + remediation, never detection alone

01 · Unit of work

Fix Plans

Every finding ships as evidence + root cause + a machine-executable diff. States: proposed → approved → applied → verified (or rolled back). Nothing is ever just "an alert."

02–03 · Fix class

Conflict Resolution & Pre-flight Gate

When flows fight over a resource: guard-condition diffs, scoped writers, cycle breaking — user picks, Switchboard applies. New flows are analyzed against the estate before they can do damage.

04 · Fix class

Silent-Failure Repair

Entity resolution knows a resource's identity, not its old name — so a renamed sheet or moved column becomes a re-pointing patch; expired credentials route re-auth to the owner.

05 · Fix class

Rollback & Version Control

Every definition version snapshotted and restorable — git for citizen automations, including the revert. "Broken since Sara's Thursday edit" is a 30-second fix.

06 · Safety

Verification Loop

Post-fix telemetry watched against the learned baseline; recovery confirmed, auto-rollback if anything regressed. The machine check on the machine's own fixes.

07–09 · Foundation

Connectors, Sensing & Guardrails

Read+write connectors (Make, Power Automate, n8n) with API round-trip verified Aug 2026; dependency graph + entity resolution to aim the fixes; snapshot-first writes, owner consent, full audit trail.

07Features · Secondary
Fig. 07 Slide B — secondary features · section 3 of 3

Supporting tier: valuable, cuttable, none of them load-bearing

Estate Health Report

Weekly service ledger to stakeholders — N detected, M auto-fixed, K approved-fixed, 0 rolled back. Reporting on the core loop, not part of it.

Zapier Monitor-Only Tier

No public write API for zap definitions, so fixes ship as step-by-step instructions. An honest product tier; deferred so the PoC stays on writable platforms.

Orphan Re-Homing

Executed succession when an owner leaves: transfer, re-bind connections, confirm next runs. High value, but independent of the fix-synthesis contribution.

Auto-Apply Policy Engine

Top rung of the policy ladder (advise → approve → auto). Core ships the first two rungs; full autonomy is a policy feature, not a research one.

Clone-Testing Harness

Validate fixes on a cloned scenario before touching production, where platforms support it. Strengthens guardrails; snapshot + verify loop already covers safety.

LLM Fix Explanations & NL Queries

Plain-language diffs and estate questions in natural language. Polish on the consent workflow, not a dependency of it.

Replay of Missed Runs

Re-trigger runs lost during an outage where the platform supports it. Extends repair from "fixed" to "made whole" — a stretch goal.
